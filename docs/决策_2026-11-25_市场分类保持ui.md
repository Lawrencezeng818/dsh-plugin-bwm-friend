# 决策 · DSH 市场分类保持 `ui`，不改 `theme`

- 日期：2026-11-25
- 对象：`data/plugins/Lawrencezeng818__dsh-plugin-bwm-friend.yml` 的 `category` 字段
- 结论：**保持 `ui`**
- 裁决人：创世者授权 agent 代定（创世者 2026-11-25「P3 分类你帮我定」）

## 一、结论

分类维持 `ui`。不因「theme Tab 曝光更高」而改。

## 二、决定性依据：theme 是互斥单例，不是标签

`dsh-market` 的 `src/themes.ts` 头注释原文：

> Theme lifecycle: classifying installed packages as themes (by the registry's theme
> category), live-toggling bundle-layer entries through the loader, and **keeping
> exactly one theme active** with the choice persisted across restarts.

`activateTheme(name)` 的实现会把其它 theme 类条目 `setEntryDisabled(..., true)` 关掉。这意味着一旦归入 `theme`：

| 场景 | 后果 |
|---|---|
| 用户激活任意其它主题（该分类现有 459 条可选） | 本插件被禁用 → `/bwm-friend/` 工作台、数字人形象、语音全部消失 |
| 用户激活本插件 | 用户原本的美化主题被关掉 |

这是**功能事故**，不是曝光收益。工作台是有业务端点的应用（settings / inventory / status / work / voice），不该被主题切换器当成互斥皮肤管理。

## 三、支撑依据

1. **归类开关是目录的 `category`，不是仓库自述**：`themes.ts:141` 是 `registry.plugins.filter(p => pluginCategories(p).includes('theme'))`。同时皮肤还可由 `skin.json`（须含非空 `id`）被识别（`hasSkinManifest`）——本仓库**没有 `skin.json`**，即从未自认皮肤。
2. **本插件不属于「外观增益」**：`theme` 类 459 条实测形态是配色（parchment / CRT cyber-green）、壁纸、启动动画、Matrix 雨——全部是替换或叠加视觉。本插件经 `/?bwm=embedded` 把**原生会话视图原样 iframe 嵌入**（不改其外观），另开 `/bwm-friend/` 页面，带 settings/voice/task 业务端点。属页面级外壳 + 功能，不是换肤。
3. **官方那句「theme/skin 放这里」的前提是「你就是个 theme/skin」**：`contributing.md` 说的是「能一键安装/切换/卸载的皮肤」，目的是不让皮肤混进 UI 增强，而非把所有带皮肤的插件都收进去。
4. **分类不是硬闸门**：目录里有一条注释——「维护者认为更合适时会直接改，不会打回」。即分类判断错了不会导致 PR 被拒，但**改错方向由维护者承担成本**；我们不该主动把功能插件塞进互斥分类。

## 四、反面意见（记录在案，不采纳）

「theme Tab 有一键安装/切换入口，转化高一个量级」——事实成立，但收益被「互斥」抵消：用户在主题 Tab 每换一次主题，本插件就消失一次，投诉与卸载的成本高于入口带来的曝光。用曝光换稳定性不划算。

## 五、顺带发现的一个真实歧义（待处理）

条目描述现在写的是 `Digital-human workbench **skin** for the DSH web UI`，而 `contributing.md` 明确要求 skin 放 `theme`。**描述自称 skin、分类填 ui，构成自相矛盾**，是把 PR 打成 `held` 的合理理由。

处理方式：把 `skin` 改为 `shell`（中文「外壳」已是既有用词，无需改）。**不夹带在 #18604 里**——那个 PR 只做「删注记」一件事，混入改词会让评审看不懂，且白跑一次约 32 分钟 CI。与 `icon` 一起并入下一批。

## 六、触发重审的条件

只有一种情况应改判：我们另出一个**真正的纯皮肤包**（只换配色/背景/字体，不改任何业务流），放在同仓 monorepo 子目录、带 `skin.json`，单独提一条 `category: theme` 条目。此时 `ui` 主包与 `theme` 皮肤包**并存**，是两个产品，不是一个分类选择。

在此之前，`ui` 不动。
