# 发布政策 · 随包内容禁专利字样 · v1.0

> 制定：2026-10-06（P0-2 发布门禁整改 · 依据整改单 v3.2，创世者 2026-10-05 政策裁定）
> 状态：🔴 内部治理类文档——**不入包**（随 P0-D 出包机制排除，见第五节）
> 签署链：小莱起草派单 → 小码实现 → 小沈终审 → 小莱复验合入

## 一、规则（创世者立）

**随包发布文件（`package.json` `files` 白名单内任何文件，含 npm 自动包含文件）禁止出现任何专利相关字样**——中文「专利 / 交底书 / 权利要求」、英文 `patent`（一律大小写不敏感，涵盖 `Patent` / `patent_role`）。

理由：**正常的开发包本来就不该含专利词语**——专利是内部资产，不是产品的一部分（0.6.0 事故定性：泄漏面是「随包内容」，不是「files 配置」；`files` 已收紧后白名单内的 `CHANGELOG.md` 与 `presence-dictionary.json` 仍带未公开专利映射，即本政策要封的形态）。

## 二、检查机制（规则不配检查 = 靠自觉 = 迟早复发）

三道机制**共用同一张词表**——单一来源 `scripts/patent-wordlist.mjs`（消毒与守卫分用两张表 = 口径漂移 = R35 高1 的 docs 漏项根因，禁止）：

| # | 机制 | 位置 | 作用 |
|---|------|------|------|
| 1 | 消毒走查（复验义务判据） | `scripts/audit-pack-patent-words.mjs` | 对**真实随包清单**全量枚举（`npm pack --dry-run` 文件清单，含 `package.json`、`packages/bwm-protocol/README.md` 等 npm 自动包含件；支持 `!` 语义，但本仓出包**不使用**负模式——理由见第五节），命中 ≥1 处 exit 1 |
| 2 | 发布门禁 P 面（P-word） | `scripts/audit-release.mjs` | 对真实 `npm pack` 产物解包逐行扫描，命中即红牌 `[P]`（无豁免）；`prepack` / `prepublishOnly` 强制执行 |
| 3 | docs 出包分类（判据一） | `scripts/classify-docs-release.mjs` | `docs/` 全量枚举：含词表字样的文档一律出包（判据二：内部运维/威胁模型/评审口径/交接类不依赖词表，一律出包） |

## 三、复验义务

- 任何触碰随包内容的改动（`files` 白名单增删、随包文档/代码措辞变更），**必须**重跑 `node scripts/audit-pack-patent-words.mjs`，0 处方可提交。
- 发现词表本身的增补需求（如新专利术语），只改 `scripts/patent-wordlist.mjs` 一处——三道机制自动同步；**禁止**在任何一道机制里私设第二张表。
- 解包断言（验收①）：`npm pack` 产物解包后词表命中必须为 0。

## 四、解冻切换（冻结期终局出口）

冻结是有期限的工程状态，不是永久豁免。**解冻（内核迁出 bundle）后，`prepack` 须由 `--expect-blocked` 切回严格口径**。**解冻动作清单**（首项即切换本身）：

1. `package.json` `prepack` 由 `node scripts/classify-docs-release.mjs && node scripts/audit-release.mjs --expect-blocked` 改回 `node scripts/classify-docs-release.mjs && node scripts/audit-release.mjs`（完整链含 classify 前置，仅切换 audit 段；严格口径：红牌即 exit 1，无冻结期豁免）；
2. 复核 `scripts/audit-release.mjs` 的 `CORE_FINGERPRINTS` 时效——内核已迁出 bundle 后指纹应转为零命中哨兵（若仍命中，说明迁移不彻底或指纹过期，**禁止切换**）；
3. 全量重跑检查：`node scripts/audit-pack-patent-words.mjs`（0 命中）、`node scripts/audit-release.mjs --selftest`（PASS）、`npm pack`（prepack 严格口径下正常收包）——全绿方为解冻生效。

冻结期口径（`--expect-blocked`）的放行条件见 `scripts/audit-release.mjs` 头注：`a+b===0 ∧ (F>0 ∨ c>0) ∧ P===0 ∧ Pword===0`——**任何 P 类命中（P-sec/P-app/P-pub/P-word）冻结期一律不放行**，与内核红（F/c）共存同样阻断。

## 五、本文件自身的出包处置

本文件属内部治理类 → 随 P0-D 出包机制排除。出包机制采用**等效机制**：`package.json` `files` 对 `docs/` 显式入包枚举（白名单只列产品/协议/规格类文档）——不使用 `!` 负模式，因负模式条目必须写出内部文件名，会把政策关键词写进必然随包的 `package.json`，反被第二节机制 2 的 P-word 守卫拦截。本文件标题即含政策关键词，属判据一/判据二双重命中，**永不入包**。
